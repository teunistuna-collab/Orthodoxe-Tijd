# Heiligenverrijking

De bestaande heiligendatabase blijft leidend. `src/lib/saintEnrichment.ts` bevat gecontroleerde Nederlandse biografische verrijkingen voor heiligen die betrouwbaar aan een profiel van Orthodox Saint Finder / Cloud of Witnesses konden worden gekoppeld.

Belangrijk:
- Geen automatische naam-match zonder controle.
- Geen ontbrekende biografische feiten verzinnen.
- Een heilige zonder betrouwbare verrijking houdt de bestaande korte tekst.
- De bron wordt in de footer algemeen vermeld.
- Nieuwe verrijkingen kunnen veilig aan `SAINT_ENRICHMENT` worden toegevoegd.
